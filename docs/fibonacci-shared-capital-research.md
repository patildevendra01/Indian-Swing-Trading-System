# Fibonacci Shared-Capital Portfolio Replay

This second-stage research step replays the already generated
`fibonacci_pullback_trades.csv` under the configured shared account constraints.
Each ratio and chronological period is treated as a separate portfolio.

## Run in Colab

After running the independent Fibonacci pullback simulator:

```bash
python -m src.fibonacci_portfolio_research \
  --input fibonacci_pullback_trades.csv \
  --config config.yaml
```

Outputs:

- `fibonacci_portfolio_trades.csv`: accepted and resized positions
- `fibonacci_portfolio_rejections.csv`: entries rejected by cash/position rules
- `fibonacci_portfolio_summary.csv`: portfolio-level results by ratio and period
- `fibonacci_portfolio_report.md`: methodology and interpretation

## Portfolio rules

- Starts each ratio/period replay with configured capital (normally ₹15,000).
- Caps each entry's planned price risk at configured risk budget (normally 0.5%).
- Caps each position at configured maximum value (normally 25%).
- Enforces configured concurrent-position cap (normally 3).
- Enforces available cash and one open position per symbol.
- Recalculates quantity from the shared portfolio constraints.
- Applies the configured delivery cost model and adverse slippage per side.
- Keeps capital reserved through the exit date and releases proceeds on the following session.
- Simultaneous entries are considered in stable symbol order; no unsupported signal ranking is inferred.

## Important limitations

This is a portfolio allocation replay of precomputed daily-bar trade outcomes. It
does not re-run the OHLC stop/target path after resizing; price exits and exit
dates remain those generated by the independent-symbol simulator. Drawdown is
realized trade-close drawdown, not daily mark-to-market drawdown. It is not a
fresh validation because the historical OOS period has already been examined.

A candidate still needs independent data/cost review and a genuinely future
paper-trading validation window. This module does not change the scanner,
baseline strategy, account settings, or authorize live trading.
